================================================================================
                    HOW TO GET CORRECT GEMINI API KEY
================================================================================

PROBLEM: Your current API key format is incorrect
Current key starts with: AQ.Ab8RN6J...
Correct Gemini keys start with: AIza...

SOLUTION: Get a new API key from Google AI Studio

================================================================================
                         STEP-BY-STEP GUIDE
================================================================================

STEP 1: Open Google AI Studio
------------------------------
Open your browser and go to:
https://aistudio.google.com/app/apikey


STEP 2: Sign In
------------------------------
Sign in with your Google account


STEP 3: Create API Key
------------------------------
1. Click the button "Get API key" or "Create API key"
2. You'll see options:
   - Create API key in new project (RECOMMENDED)
   - Create API key in existing project

3. Click "Create API key in new project"


STEP 4: Copy the Key
------------------------------
Your API key will appear. It should look like:
AIzaSyD_xxxxxxxxxxxxxxxxxxxxxxxxxxx

IMPORTANT: The key MUST start with "AIza"
If it doesn't, you got the wrong key!


STEP 5: Add to .env File
------------------------------
File location: d:\Nebula\ethonline\packages\nextjs\.env

Replace the old line with:
GEMINI_API_KEY=AIzaSy...YOUR_NEW_KEY_HERE


STEP 6: Test It
------------------------------
cd d:/Nebula/ethonline/packages/nextjs
npm run ai:test test-policy-usdc-1

================================================================================
                         TROUBLESHOOTING
================================================================================

Q: My key doesn't start with AIza
A: You might have copied a different type of Google API key.
   Make sure you're on https://aistudio.google.com/app/apikey
   NOT Google Cloud Console

Q: I can't access Google AI Studio
A: Try these URLs:
   - https://aistudio.google.com/app/apikey
   - https://makersuite.google.com/app/apikey

Q: Still not working?
A: The key format in your .env is wrong. Valid keys look like:
   AIzaSyD_xxxxxxxxxxxxxxxxxxxxxxxxxxx (39-40 characters total)
   Your current key: AQ.Ab8RN6J... (wrong format)
